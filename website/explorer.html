WUP Grid Explorer

The explorer is now a self-contained app served by the Python package (map, charts, step traces, saved results, known-fire checks). Start it with one of:

  • double-click WUP_Explorer.exe (no Python needed; built by the Build WUP Explorer GitHub Action), or
  • double-click WUP_Explorer.bat in the repository folder, or
  • python -m aorc_tools.explorer

It opens http://127.0.0.1:8765/. If an explorer is already running on this computer, that link opens it.
